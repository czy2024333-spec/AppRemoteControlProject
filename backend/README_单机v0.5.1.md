## VSCode运行

打开本目录，选择现有rotorpy-day1的Python解释器。若尚无环境：

```powershell
python -m pip install -r core/requirements.txt
```

F5选择“三来源完整切换演示（临时本机服务）”，无需先启动服务器：

```powershell
python run_handover_demo.py
```

演示通过真实HTTP执行APP→指环→语音→APP，每次有用户切换和中立握手。结果在results/handover/，包括轨迹图、原始状态、命令确认耗时和摘要。

手机联调选择“三来源局域网服务”或运行：

```powershell
python app_server.py --host 0.0.0.0 --port 8765
```

手机用电脑局域网IPv4，如http://192.168.1.20:8765。APP、指环适配器、语音适配器使用各自Token，不能混用。

```powershell
python -m unittest test_boundary test_ctl test_inputs -v
```

这是仿真联调服务：指环的蓝牙协议、语音识别和手机画面由前端适配；core中保留的旧UE骨架没有升级。未加入航点任务或GNSS。Python环境与离线安装包不包含在本包中。v0.3协议请求不能原样用于v0.4。
