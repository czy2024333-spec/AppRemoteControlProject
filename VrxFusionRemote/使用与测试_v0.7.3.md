# v0.7.3 当前位置近景与透明提示

继续覆盖手机已有“旋翼遥控·优化版”，版本码703。同包名、同签名，不新增图标；不要先卸载旧版。

## 怎么使用

1. 安装 `旋翼遥控APP-v0.7.3-覆盖更新.apk`，选择更新，从原图标打开单机操控。
2. 轨迹图保留原来的位置和大小，面板内直接显示X、Y、Z坐标，单位为米；不显示“位置与轨迹”标题，也不显示“近景／远景／总览”等模式文字。
3. 默认是缩略总览，自动容纳原点、当前位置及APP已经接收到并保留的轨迹；不再固定裁掉±10米之外的路径。
4. 单击该面板，切换为**当前位置近景**。观察中心跟随飞机当前位置，显示附近约5米的平面范围，网格同步换算；只放大局部观察比例，不扩大地图框。
5. 再单击一次恢复总览。两种模式都不会移动地图、姿态仪、摇杆或关键按钮，也不会切换控制权、发送运动指令。横竖屏保持同一个操控页。
6. 底部状态提示框背景完全透明，保留标题、状态说明及告警颜色，文字增加黑色描影；“详情”按钮和弹窗已移除。

近景优先看清当前位置附近的运动，较远的历史轨迹可能在框外；查看整条已接收轨迹时切回总览。
这不是卫星底图或地理导航：上方为+X，左方为+Y，Z高度直接以文字显示。
轨迹只代表APP本次连接收到并保留的数据，不代表从飞行开始就完整记录。

## 保留的设置

右上角齿轮仍提供连接及显示设置。摇杆、姿态仪、地图、位置读数的不透明度分别可调并自动保存。
顶部停止/保护等关键按钮和底部提示文字不受这些滑块影响。
UE全屏容器继续保留，姿态仪和地图同时可见；现有工程仍需UE方提供实际视频源才能显示UE实景。
后端地址、Token、申请控制、保护解除、安全校验及三机只读监控沿用原版；后端无需因本次界面更新而更换。

## 手机测试顺序

1. 更新后检查只有原来的应用图标，原后端地址仍在。
2. 连接后端、申请控制，在安全范围内移动飞机，确认地图内XYZ和轨迹都更新。
3. 单击轨迹图：飞机保持在观察中心，附近的轨迹更清楚，比例尺变小；地图框大小和位置完全不变，没有模式标题。
4. 再点恢复缩略比例，应重新显示全部已接收并保留的轨迹；反复点击不能触发运动或控制权切换。
5. 分别在横屏和竖屏操作，确认姿态仪、双摇杆、关键按钮没有被地图遮住。
6. 检查底部状态只有文字，没有有色底框和“详情”；触发保护、暂时断网时仍应看到相应颜色及原因。
7. 把地图不透明度调低，提示文字及停止/保护按钮应保持清晰。

真机字体、亮色UE视频叠加及实体手机手势仍需要按以上步骤复测。交付截图来自实际Compose界面渲染，使用固定样例状态，不是手机或UE实景录像。

源码继续在原 `VrxFusionRemote-v0.7` 工程迭代；关键逻辑已有中文注释。交付源码不包含本机SDK路径和签名私钥。
