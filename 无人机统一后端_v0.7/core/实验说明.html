文件你今天的动作

requirements-lock.txt / official_sources.json分别锁依赖版本、锁官方源码提交及每份文件SHA256。
results/versions.json本次解释器、包版本、实际导入源码位置和哈希记录。

Environment负责调用和记录。控制器不直接修改位置；模型也不自动知道你想去哪。实际状态回到控制器，构成反馈闭环。今天使用真实仿真状态反馈（use_mocap=False），不是传感器估计闭环。

target = trajectory.update(t)
control = controller.update(t, state, target)
next_state = vehicle.step(state, control, dt)

以上是核心关系示意；实际教学脚本先调用官方Environment.run。单步接口在单元测试中已验证，下一步才能封装自己的持续调度服务。

state字段含义 / 单位常见误解
x世界系位置[3]，m不是目标位置，不是经纬度。
v世界系速度[3]，m/s不是APP机体系摇杆值。
q姿态四元数[4]，排列[x,y,z,w]不是roll/pitch/yaw。单位四元数[0,0,0,1]表示无旋转。
w机体系角速度[3]，rad/s不是欧拉角变化率，不能直接把四元数标量w当成它。
wind世界系风速[3]，m/s由风场对象更新。
rotor_speeds每个电机的实际转速，rad/s与cmd_motor_speeds命令转速不同，有响应滞后。

模型z轴向上、重力向下；坐标约定和旋转正方向要以保存的源码为准。之后接UE时不能直接原样拷贝位置/四元数：单位与左右手坐标转换需要独立验证。

四、机体参数与控制器怎么理解

参数本次值单位意义
mass0.03kg质量。首日是Crazyflie小机型，并非甲方机型。
Ixx / Iyy / Izz1.43e-05 / 1.43e-05 / 2.89e-05kg·m²转动惯量，决定力矩产生的角加速度。
num_rotors4个当前为对称四旋翼。
rotor_pos见参数源码m各电机相对重心的位置，决定推力产生的力矩。
k_eta2.3e-08N/(rad/s)²单旋翼推力近似T = k_eta × omega²。
k_m7.8e-10N·m/(rad/s)²旋翼反扭矩系数，影响偏航。
tau_m0.072s电机一阶响应时间，实际转速不会瞬时等于命令。
rotor_speed_max2500rad/s电机转速上限，不是rpm。
对称四旋翼静态悬停近似：4 × k_eta × omega² = mass × 9.81。
本次质量 0.030kg，总支撑推力约 0.2943N，初始平衡转速约 1788.55rad/s。
初始就位于1m高度且电机处于平衡转速；这不是起飞过程。

SE3Control先根据位置误差和速度误差算期望力，再结合偏航目标算期望姿态，通过姿态/角速度误差算力矩，最后分配到四个电机。

kp_pos=[6.5, 6.5, 15.0]，kd_pos=[4.0, 4.0, 9.0]。位置P增益代表纠偏力度，D项提供阻尼；增益越大不一定越好，可能激发振荡及电机饱和。

本次mass_scale同时改变模型和控制器的已知质量，并保持原惯量/几何。它只是控制教学实验，不是模型失配测试，也不能当作真实新机型。示例气动参数含近似值，需要后续标定。
