# v0.9.2 入口统一与日志优化

覆盖安装`旋翼遥控APP-v0.9.2-覆盖更新.apk`，沿用“旋翼遥控·优化版”的包名与签名，无需卸载。版本902 / 0.9.2。本轮只修改前端，依据GitHub主分支5dafd473及其2026-11-05日志验证记录进行适配。

## 入口现在如何使用

首页保留两个工作入口：独立操纵、三机只读总览。地址、Token和身份预设统一在顶部次级入口“连接与设备管理”填写。

操纵设置的“连接状态”和三机总览只显示连接摘要与“管理连接”按钮，没有另外的地址或Token输入框。未连接时点操纵页“连接设置”，也进入同一个管理页。管理页展示后端确认的实际身份、绑定设备及能力，位置、速度和告警在操纵页或总览查看。

从操纵页进入管理，会先停流并释放旧控制，视频停止。确认地址和实际身份后，点“返回操纵”回原页；从总览进入则显示“返回总览”。系统返回键同样返回原页。不会自动接管或恢复旧运动，仍须松开双摇杆后主动申请控制。

从首页进入管理，返回首页后可复用前台观察连接，再选择工作页。进入后台后连接仍按原规则停止，回前台需主动重连。

## 配套后端

原始v0.9后端可继续操纵，但没有日志能力时，APP会明确提示日志未开放。要测试本轮日志功能，请使用GitHub合并日志修复后的后端。

从仓库根目录打开 PowerShell，并使用已安装后端依赖的 Python 环境。

```powershell
Set-Location -LiteralPath .\backend
python .\run_backend.py --mode independent --host 0.0.0.0 --port 8765
```

手机与电脑连接同一局域网，APP 地址填 `http://电脑IPv4:8765`。身份使用现有公开开发预设，实际角色与绑定以后端确认为准。

## 日志查询与导出

1. 连接声明日志能力的后端，进入独立操纵的“飞行设置 → 连接状态”，向下找到“服务端审计日志”。观察端同样可查询，无需申请控制。
2. 选择全部或指定设备、时间范围，可填写事件编码，例如`MEMBER_STARTED`或`COMMAND_ACK`，然后点“查询 / 刷新”。每页最多20条。
3. “下一页”沿用同一筛选、固定snapshot与后端next_offset。修改筛选后，必须重新查询，旧页的翻页和导出会停用。
4. 导出JSONL或CSV使用当前查询快照和筛选，包含全部匹配内容，不仅是当前页。先有界下载至APP临时文件并校验，再弹出系统保存位置选择器。
5. 保存选择器会使APP进入后台，按既有规则释放控制；返回后需手动重新连接和申请。取消保存或保存失败会清理临时文件；失败的目标文档会尝试删除，不显示保存成功。

单次下载最大16MiB，读取前及读取中都检查，未知长度或分块传输也受限制。超过上限请缩小设备或时间范围，重新查询后导出。下载中断或应答格式异常不会进入保存流程。CSV保留UTF-8 BOM。

索引建立中、日志繁忙、快照失效、数据损坏和文件读取失败分别提示错误码与请求编号；不会把这些日志错误改写成飞控连接失效。快照失效时重新查询第一页。损坏日志不自动切换为部分导出。

日志来自异步落盘和后台索引，可能未追平或有未写完尾行；页面会显示相应提示，不当作实时飞行状态。单次只执行一个日志操作，可取消。

## 按顺序复测

| 步骤 | 操作 | 预期 |
|---|---|---|
| 1 | 首页、操纵设置、三机总览逐个查看 | 只有管理页可编辑地址/Token；其他处为摘要与跳转 |
| 2 | 从未连接的操纵页进入管理、连接、返回 | 返回原操纵页；先观察，不自动接管 |
| 3 | 接管后打开设置再进入管理 | 旧会话停流并释放；返回重连后需重新申请 |
| 4 | 从总览进入管理，再按系统返回 | 回到总览，仍只读，可看三机位置与状态 |
| 5 | 查询指定设备的MEMBER_STARTED日志 | 看见实际匹配结果；修改筛选后旧页导出停用 |
| 6 | 导出JSONL与CSV并保存，再取消一次 | 文件有效；取消不显示成功；回前台不恢复控制 |
| 7 | 使用大范围历史导出或遇到503 | 提示缩小范围/稍后重试，不自动切换角色或接管 |
| 8 | 显示布局中点“恢复显示默认值”，再回退配置 | 仅一个恢复默认入口，原配置自动保存为回退点 |

本机自动化与三机并发结果见本版验证报告。手机系统文件选择器、实际局域网、指定终端、UE、外设及4小时持续运行仍待现场验收。
