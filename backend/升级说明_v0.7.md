# 无人机统一后端 v0.7 升级说明

日期：2026年10月16日。本版基于v0.6主线，覆盖当前Python三维仿真、三来源输入、边界迟滞、集群、模拟测量、SDK适配参考及联调工具。历史C++核心和UE骨架保留为参考，不作为本版已编译验证的运行组件。现有手机APK与UE EXE仍由对应负责人接入。

## 本版变更

1. 单机与集群共用严格HTTP解析：拒绝不完整、重复字段、非有限数值、非法分块请求；错误连接关闭，避免残余数据成为下一条控制请求。响应和HTTP头提供请求追踪编号。
2. 新增精确Origin跨域白名单及OPTIONS预检，默认不开放跨域；鉴权、控制权、归中和保护校验不变。提供浏览器fetch读取JSON/SSE的示例。
3. 集群替换指环/语音会话时，如该来源仍选中、执行或等待归中，会撤销旧控制对象并保护，防止旧连接继续操纵。
4. 指环begin/update批采样按连续输入处理，不再占用离散幂等历史；参考客户端同步修正中立握手的成员控制轮次。
5. 超时且尚未开始的队列请求取消执行。已开始而结果未知时返回ACK_OUTCOME_UNKNOWN，不能假称回滚或自动重发运动，需查询命令与最新状态。
6. 集群拒绝请求记录可关联原因；命令查询和注销共享锁，接管前必须确认旧、新目标均已清除输入，不能只检查新对象。
7. 模拟测量采用绝对采样节拍，修复30Hz等非整除频率逐渐降频问题；仍使用每架独立随机源。
8. 完整校验启动配置后才创建实例，控制配置按成员保存；材料检查按必测清单核对，删掉项目或空对象不再漏报。SDK日志仅记录协议允许字段。
9. 新增run_backend.py统一启动、自检和/api/health健康接口；run_checks.py统一回归，启动失败给出依赖、配置或端口原因。

## 步频及容量

当前开发基线仍为3架在线、3架受控、3架启用模拟位置/速度测量。在本机全量回归中，三机100Hz出现调度积压；本版提供dynamics.sim_rate_hz逐实例配置，三机样例改为各50Hz，单机默认100Hz。保护的100ms长帧/调度积压阈值和输入TTL没有放宽。

集群状态流目标25Hz，样例模拟测量目标20Hz。仿真步频、状态推送频率、传感器采样率与APP渲染率是不同指标，应分别测量。更高实例数或步频必须在目标硬件验证，不能仅修改配置就视为通过。

## 运行与兼容

```powershell
python run_backend.py --doctor
python run_backend.py --mode cluster --host 0.0.0.0 --port 8765
python run_backend.py --mode single --host 0.0.0.0 --port 8765
python run_checks.py
```

单机和集群服务择一运行，不能同时占用同一端口。实现版本为0.7.0；单机api_version仍为0.5，集群api_version仍为0.6，原字段、单位、会话及三维坐标保持兼容。健康检查需原有Bearer Token；保护中的仿真可以是健康运行状态，healthy不代表允许操纵。

浏览器前端如来源为http://localhost:5173：

```powershell
python run_backend.py --host 0.0.0.0 --allow-origin http://localhost:5173
```

Origin是网页本身的协议、主机与端口，不是后端地址；多来源重复传--allow-origin。跨域白名单没有通配符，不接受null来源；不要直接双击HTML用file协议运行。

另开终端在examples目录运行python -m http.server 5173 --bind 127.0.0.1，浏览器打开http://localhost:5173/browser_state.html。输入后端地址和对应Token后可以检查健康、读取状态和带Authorization头接收SSE。此示例为状态诊断页面，不是ADP可配置控件系统，也不提供运动输入。

## 边界恢复与三来源

保留v0.5.1的迟滞：默认高度下限0.30米，至少恢复到0.35米且合速度不超过0.05米/秒才允许解除；边界保护目标最低0.40米，通过真实动力学移动，不瞬移。上限与水平边界同样有内侧余量。APP继续处理BOUNDARY_RECOVERY_PENDING，并以实际状态和归中握手为准。

集群替换输入来源会话可能使selection_id失效，前端必须重新读取选择状态；每架APP监督心跳仍需维持，不能因为正在握手、切到语音或指环就停发。SDK、手机识别结果仍经过置信度、映射、权限与危险动作确认。

## 明确未完成的能力

甲方指环、语音硬件及SDK尚未提供，真实硬件验收未完成。起飞、降落、返航任务仍返回501；GNSS、航点、自主任务分配、编队保持、协同避障及ADP控件配置系统不计为本版完成。集群正式数量、目标硬件、手机和UE现场指标仍待联合验收。

测试与实测结论见本包验证报告_v0.7.md；旧版报告仅作历史参考，不代表本版新增能力通过。
