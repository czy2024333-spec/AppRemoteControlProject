# 旋翼遥控·优化版 v0.7 使用与测试

适用：Android 10及以上；电脑与手机在同一局域网；后端使用负责人A的v0.7代码包。

## 1. 安装和入口

安装交付目录中的 `旋翼遥控APP_v0.7_优化版-debug.apk`，桌面名称为“旋翼遥控·优化版”。
调试版本包名为 `com.vrxfusion.remote.optimized`，可与原APP同时安装。无需卸载原APP。

打开后：

- **单机操纵**：负责人A后端的单机HTTP接口，三维双摇杆、遥测、保护恢复、横屏姿态和轨迹。
- **三机监控**：负责人A后端的集群HTTP接口，实时成员状态、小组筛选、位置示意；本入口只读，不创建控制会话。
- **旧版设备目录**：保留前端原有8767 WebSocket服务、本地演示与设备目录；其演示数据不等同于负责人A的动力学数据。

横屏中UE视口仍为占位，XY地图为后端遥测绘图，不是UE视频。

## 2. 启动单机，先完成一次操纵

在电脑PowerShell执行以下完整命令，不依赖当前目录和系统默认Python：

```powershell
& "C:\Users\24107\.workbuddy-ai\binaries\python\envs\rotorpy-day1\Scripts\python.exe" "C:\Users\24107\Documents\Codex\2026-10-11\new-chat\outputs\无人机统一后端_v0.7\run_backend.py" --mode single --host 0.0.0.0 --port 8765
```

如果8765已被之前的集群服务占用，在旧服务窗口按Ctrl+C后启动；或者把单机改为8766，并在APP地址中使用8766。

运行 `ipconfig`，找到电脑正在使用的Wi-Fi或以太网适配器的IPv4，例如 `192.168.1.23`。
手机点“单机操纵”，填写：

- 地址：`http://192.168.1.23:8765`（替换为电脑实际IPv4）。
- APP来源Token：`demo-app-token-2026`（不加Bearer）。

不要在手机里填写127.0.0.1、localhost或0.0.0.0。Android原生HTTP请求不需要浏览器CORS参数。
首次网络提示允许Python在专用局域网通信。修改地址或Token前先断开连接。

操作顺序：

1. 点“连接并查看状态”，等待出现真实位置和实时接收频率；刚连接不申请控制权。
2. 保持双摇杆松手，点“申请APP控制”，等待“APP控制已就绪”。
3. 右杆上推前进、下推后退、左右平移；左杆上推上升、下推下降、左右转向。移动方向沿当前机头。
4. 松手后自动发送停止。下一次推动视为新的操纵事件。
5. 点“保护锁存”观察PROTECTED；双摇杆物理松手，等安全区/速度条件满足，再点“解除保护”。
6. 解除后保持HOLD，需重新点“申请APP控制”。进入后台、退出或断线后也不会自动恢复旧运动。
7. “横屏操作”可查看姿态仪、相对位置、轨迹和高度带。切换页面会结束当前手势；如通路未就绪，重新申请。

注意：当前后端默认从空中悬停开始，尚未实现任务级起飞、降落、返航。下降摇杆不等同于完整降落任务。
单机停止按钮撤销当前运动；需要继续时按界面提示申请。安全保护始终以后端校验为准。

默认显示sim-drone-1、2、3；alpha包含1、2，beta包含3。筛选只改变显示，不改变后端控制对象。
地图上方为+X，左方为+Y；颜色对应图下的成员图例。成员失联或状态过期时标注历史状态，不显示为正常在线。

三机入口本次只做监控。集群摇杆控制、成员接管及逐机应答交互仍需下一阶段接入，不能用单机接口代替集群接口。

## 4. 建议真机验收记录

| 测试 | 预期 |
|---|---|
| 填错Token | 提示401，不发送控制 |
| 单机页连接集群端口 | 提示接口不匹配，引导切到集群监控 |
| 只点连接 | 可观察状态，不自动创建会话或申请APP通路 |
| 主动申请控制 | 双杆松手后switch→neutral成功 |
| 两杆分别及同时操作 | XYZ/偏航方向正确，松手停止 |
| 横竖屏互切 | 状态订阅保持；旧手势不跨页面续发 |
| 手持摇杆时触发保护 | 输入停发，未物理松手时不能解除 |
| 高度下边界 | 显示安全余量与停稳条件，未满足时解除按钮禁用 |
| 断Wi-Fi再恢复 | 停发；恢复只读状态；不自动续控 |
| APP切后台再回来 | 停止/断连；需重新连接及申请 |
| 三机监控与分组 | 三成员独立状态；alpha两架，beta一架；不会申请控制权 |

接收Hz是APP客户端收到新物理步号的频率，最近应答是客户端一次操作的往返耗时；均不是完整APP渲染帧率或端到端P95验收证明。
真实手机的触摸、布局、局域网表现与UE画面需按本表另行验证。

## 5. 编译源码

打开 `VrxFusionRemote-v0.7` 目录；建议工程放在英文路径，避免旧版Gradle在Windows中文路径下加载单元测试类失败。
工具：JDK17、Gradle8.7、Android SDK Platform34、Build Tools34。保留原有Compose/Kotlin版本。
在 `local.properties` 写入本机SDK路径，例如：

`D:\IntelliJ IDEA 2024.1\jbr`。

PowerShell：

```powershell
$env:JAVA_HOME = "D:\IntelliJ IDEA 2024.1\jbr"
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest
```

首次构建需要联网下载依赖。APK位于 `app/build/outputs/apk/debug/app-debug.apk`。
普通单测中两条真实后端联调案例在未设置DRONE_TEST_SINGLE_URL/DRONE_TEST_CLUSTER_URL时跳过。
仅向独立测试服务设置这些变量，不能指向正在供前端操纵的共享服务。

## 6. 常见问题

- 提示“找不到run_backend.py”：使用上文带解释器和脚本完整路径的命令。
- 显示404：单机/集群入口与后端启动模式不一致。
- 显示401：Token或后端自定义Token不一致。
- 手机连不上：检查IPv4、同一局域网、Python进程和专用网络防火墙；不用启动8767旧服务来访问A后端。
- “解除保护”禁用：松开双杆并查看高度、半径、速度是否进入安全区。
- 只有悬停、位置很稳定：正常，后端在等待有效输入，不会自行自由飞行。
- 没有真实三维画面：地图和姿态来自遥测，UE画面需由UE端另行接入。
