## 当前实现与已验证内容

- 各机分别查询、编辑、保存和恢复动力学参数，采用独立版本号。
- 悬停提交后推进该机控制轮次，采用原有身份、会话、设备绑定、序号、有效期和幂等校验。
- 模型先构建、参数文件原子保存成功后再提交，仿真步号和时间持续递增。
- 控制配置与物理限幅共同决定有效控制速度，参数更新记录版本和字段差异。
- 本机回归 202 项通过，动力学 26 项通过、1 项按条件跳过。三机不同参数、GNSS、回放和九路 SSE 的 30 秒本机混合负载通过。

当前代码允许 HOLD 状态下修改质量、惯量、动力和负载。功能回归和短时负载验证涵盖了接口、状态与运行性能，物理模型的逐参数一致性仍有以下问题。

## DYN-001 的复现方式

在后端目录使用已安装依赖的项目解释器执行以下 Python 代码。它只构建候选模型并打印参数。

```python
import copy
import app_server  # 加载项目的核心模块路径
from simulation_core import SimulationCore

core = SimulationCore()
candidate = core.baseline_physics()
before = copy.deepcopy(core.params)
candidate["inertia_kg_m2"]["Izz"] *= 1.05
_, _, _, after, _ = core.prepare_physics(candidate)
for key in ("mass", "Izz", "k_eta", "k_m", "rotor_speed_max"):
    print(key, before[key], "->", after[key])
```

当前输出中 `k_eta` 和 `rotor_speed_max` 随 Izz 改动而变化。后续修正应明确各字段的预期关系，并在回归中验证。
