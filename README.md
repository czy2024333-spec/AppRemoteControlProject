# AppRemoteControlProject

当前前端版本：**v0.9.0 三机独立操控版**（2026-10-20交付，2026-10-26同步至GitHub）。

Android Studio打开仓库内的 **VrxFusionRemote** 目录，Gradle JDK选择17，Android SDK 34，最低Android 10。

- 三台手机分别选择操纵端1、2、3，独立控制对应飞机；每端操纵页均可观察三机位置，本机高亮。
- 三机只读总览显示三机位置、运行模式、状态和告警；观察端不申请控制。
- 连接后主动申请控制；换端先停止并释放旧会话，不自动恢复旧运动。
- 沿用优化版应用身份，版本900 / 0.9.0。个人签名私钥与local.properties不进入仓库。

配套用户提供的无人机独立操控后端v0.9，使用 `--mode independent --host 0.0.0.0 --port 8765`。所有手机填写同一个 `http://电脑IPv4:8765`；后端独立交付，不包含在本次前端升级中。工程内server目录为历史协议联调工具，当前三机操纵无需启动它。

已完成96项常规回归及本机60秒三机操纵、四端观察联调；7个条件用例在普通回归中跳过，其中三机后端联调另行执行通过。指定手机局域网、真实UE/外设及4小时稳定性仍待现场验收。详见报告，不以历史版本说明代替当前验收结果。
