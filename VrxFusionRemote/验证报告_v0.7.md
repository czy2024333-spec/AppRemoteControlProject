# 旋翼遥控APP v0.7 界面与功能优化验证

日期：2026-10-16。来源：用户提供的前端v0.5.1源码；原目录保持不变。

## 已完成的改动

- 新首页突出单机操纵、三机监控和旧版WebSocket设备目录，明确服务模式和数据来源。
- 单机页重排连接、状态、遥测、控制、保护恢复；显示XYZ米制数据、速度、偏航、接收频率和最近操作应答耗时。
- Token默认遮挡且不写URL、日志或磁盘；只保存非敏感后端地址；修改连接参数前必须断开。
- 单机状态从100ms轮询改为SSE事件流；独立500ms新鲜度检查，不把重复物理步号算作更新。
- 建连只读；明确点击申请控制才建会话、switch和真实中立握手；重连、后台恢复、解除保护不会自动接管。
- 运动、心跳和离散操作共用互斥锁，保持序号与回执顺序；运动失败不重试，锁后读取最新摇杆值，不补发旧快照。
- 正常松手发stop，下一次推动使用新操纵意图；保护、失联和退出会停流；后台及页面退出用ViewModel完成安全上报。
- 双摇杆跟踪真实按下状态，即使保护禁用也等待物理松手；边界安全余量未满足时解除按钮禁用，后端仍独立校验。
- 修正原包横滚与俯仰四元数解算互换；保留横屏姿态、地图和高度带，补齐安全区、忙碌、真实松手判断。
- 三机只读监控读取v0.7集群接口，支持alpha/beta筛选、成员在线和失效标记、XYZ状态与XY位置总览；不会创建控制会话。
- 优化版独立调试包名com.vrxfusion.remote.optimized，与原APP并存；操作页保持屏幕常亮。
- 关键控制、生命周期、坐标、Token处理均补充中文注释。

## 验证证据

工具：JDK17.0.10、Gradle8.7、AGP8.5.2、Kotlin2.0.20、Android Platform34 / Build Tools34。
后端：既有v0.7.0；RotorPy3.0.0；独立127.0.0.1临时端口及日志目录，不占用用户8765服务。

| 项目 | 结果 |
|---|---|
| assembleDebug | 成功，实际生成APK |
| 普通JUnit | 7条通过；2条需真实服务的案例在普通运行中按条件跳过 |
| 真实单机JUnit | 1条通过，含申请→两次新手势→停止→保护→解除→再次控制→断开→只读重连 |
| 真实三机JUnit | 1条通过，三个独立编号，selection始终为空 |
| APK元数据 | 包名com.vrxfusion.remote.optimized；版本700 / 0.7.0-ui；minSdk29、targetSdk34 |
| APK签名 | apksigner verify通过，APK v2签名 |

共9条不同测试均实际执行通过：7条普通案例，加两条分别连接真实单机/三机的案例。
普通案例覆盖欧拉角、四轴方向、连接参数、鉴权错误、禁止重定向、SSE帧解析和只读连接不POST。

真实单机测试位移约0.044m；短时接收读数约26.7Hz。三机短时接收读数约23.4Hz。
这些是本机Kotlin网络客户端的短时观察，不代表手机局域网、实际绘制刷新或端到端P95验收。
完整JUnit XML、构建与测试日志位于交付包 `验证记录/`。
