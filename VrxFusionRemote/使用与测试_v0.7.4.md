# v0.7.4 摇杆与轨迹图方向修正

覆盖安装 `旋翼遥控APP-v0.7.4-覆盖更新.apk`，保留原应用和数据。版本码704，包名和签名继续沿用v0.7优化版；后端仍使用原v0.7，不需要更换。

## 改了什么

此前右杆使用机头方向输入（frame=heading），轨迹图使用固定世界坐标。飞机转向后，两者可能不一致，例如机头朝后时左推会在图上向右。

本次将该操控页的右杆改为固定世界坐标输入（frame=world），与轨迹图保持一致；水平轴符号仍按正确的坐标约定转换一次。

| 操作 | 实际方向与图示 |
|---|---|
| 右杆向左 | 世界+Y，轨迹图向左 |
| 右杆向右 | 世界−Y，轨迹图向右 |
| 右杆向上 | 世界+X，轨迹图向上 |
| 右杆向下 | 世界−X，轨迹图向下 |
| 左杆向上／向下 | 上升／下降 |
| 左杆向左／向右 | 左转／右转，改变飞机朝向，不改变右杆相对轨迹图的方向 |

地图本身不随机头旋转。三种来源接口仍支持heading/world；本次只修改这个APP操控页的发送基准。

地图原位、单击切比例、标题及模式文字隐藏、底部透明提示、四项不透明度设置继续保留。

## 手机怎么确认

1. 覆盖安装后从原图标进入单机操控，连接后端并主动申请控制；在安全范围内测试。
2. 默认缩略图下，分别短推右杆左、右、上、下，每次松手停稳，检查飞机标记朝相应方向移动。
3. 用左杆把机头转向，再重复右杆四方向；地图中的运动方向应仍与推杆方向相同。
4. 单击轨迹图切到当前位置放大视图，再次单击恢复缩略图；地图框大小和位置不变。
5. 放大视图会跟随当前位置：飞机标记保持居中，旧轨迹和网格向相反方向滑动是相机跟随的结果。判断实际左移／右移可切回缩略图，或观察Y值：左移增加，右移减少。

本次已在独立仿真验证方向，仍需在你的手机上确认触摸和显示。现有工程继续等待UE视频源，右上轨迹图显示的是后端位置数据。
