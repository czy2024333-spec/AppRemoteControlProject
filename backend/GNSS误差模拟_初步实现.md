# GNSS 误差模拟初步实现

首次实现于 2026-11-18，更新于 2026-11-20。

本轮按确认范围实现 GNSS 噪声、漂移、延迟和丢包，输入和输出采用仿真世界系的米制局部坐标。经纬度与海拔换算列为待办。

## 已实现

每架飞机使用该成员的 `sensors.seed` 分别驱动位置噪声和丢包。同一版本、同一配置和相同输入可以复现实验。固定种子只改噪声时丢包序号一致，只改丢包率时，两组都收到的同序号测量坐标一致。随机序列在 11 月 20 日拆分，与 11 月 18 日初版逐点对比时应重新生成基线。动力学和 HUD 真值从核心状态读取。

- 采样以首次仿真时刻为起点，按配置频率计时。采样点落在相邻两个动力学步之间时，按同一比例对三轴位置及两个步的服务端 Unix 时刻做线性插值。高斯噪声按配置的每轴标准差生成。
- 线性漂移为各轴漂移速度乘以从首次采样开始经过的仿真时间。改变动力学步频或重复读取同一步号时，漂移按同一时间基准计算。
- 延迟从采样时刻起算，在延迟期满后的首个动力学步交付。样本保留采样位置、采样时刻和实际交付时刻。例如 50 Hz 动力学、20 Hz GNSS、30 ms 延迟时，50 ms 的样本由 40 和 60 ms 的真值插值得出，在 80 ms 交付。队列容量由采样率及延迟计算，允许的最大容量为 252 项。
- 丢包按采样事件的概率生成，在该事件经过延迟队列后公开。已有有效值时保留它的序号和测量时间，并标为过期。首次样本即丢失时返回空值及具体原因。
- 同一步重复发布沿用该步首次记录的位置与墙钟。相邻真值的仿真时间间隔超过一个 GNSS 周期时，跳过缺失区间，从恢复点采一次并重新计采样周期，漂移继续按总仿真时长计算。仿真时钟回退或显式重置模型时，清除旧队列、重置随机序列和漂移。

配置校验、成员初始化、独立三机和旧集群的统一状态及 SSE 入口均已接入。每成员还需启用 `sensors.enabled`，沿用现有传感器实例数量管理。

## 开启方法

在 `cluster_config.json` 中设置顶层 `gnss.enabled=true`，保存后重新启动后端。示例配置的开关默认关闭。旧配置省略整个 `gnss` 对象时按关闭处理。

```json
{
  "gnss": {
    "enabled": true,
    "rate_hz": 20,
    "noise_std_m": 0.8,
    "drift_m_per_s": [0.02, 0.0, 0.0],
    "latency_ms": 80,
    "loss_probability": 0.0,
    "stale_after_ms": 500
  }
}
```

以上对象合入原集群配置顶层。启动时在后端目录使用项目解释器运行。

```powershell
python run_backend.py --mode independent --host 0.0.0.0 --port 8765
```

| 配置字段 | 含义及范围 |
| --- | --- |
| `enabled` | 布尔开关 |
| `rate_hz` | 采样率，整数 1–50 Hz |
| `noise_std_m` | 各轴高斯噪声标准差，0–20 m |
| `drift_m_per_s` | X、Y、Z 三轴线性漂移速度，每轴 −1 至 1 m/s |
| `latency_ms` | 仿真时间下的交付延迟，0–5000 ms |
| `loss_probability` | 每次采样事件的丢失概率，0–1 |
| `stale_after_ms` | 测量年龄超过此值时标为过期，1–10000 ms |

修改参数后重启生效。测试纯丢包时可设 `loss_probability=1`，测试纯漂移时可设 `noise_std_m=0`。延迟大于过期阈值时，交付的历史数据会带过期状态。

## 接口与字段

使用当前来源凭据读取 `GET /api/v1/state` 或 `GET /api/v1/devices/{device_id}/state`。相同字段通过对应 `events` SSE 发布，启用后位于 `sensors.gnss_local_position`。单机原字段接口另含 `gnss_local_measurement`。

| 字段 | 含义 |
| --- | --- |
| `source` | 固定为 `SIM_GNSS` |
| `unit`、`coordinate_frame` | `m`、`SIM_WORLD_X_FORWARD_Y_LEFT_Z_UP` |
| `value.position_m` | 带误差的局部 X、Y、Z 位置 |
| `value.sequence` | 最后有效测量的采样序号 |
| `value.simulation_time_s` | 传感器采样的仿真时刻 |
| `value.measured_at_unix_ms` | 与采样对应的服务端 Unix 毫秒时刻，跨动力学步时按两步记录插值 |
| `value.delivered_at_simulation_time_s` | 实际交付该样本的仿真时刻 |
| `age_ms` | 采样年龄，包含仿真延迟和成员停更时间 |
| `packet_sequence` | 最近交付事件序号，丢包也会推进 |
| `lost_packets`、`pending_samples` | 累计交付的丢包数、当前队列项数 |
| `validity`、`reason` | 数据有效性及原因 |

初始等待延迟时为 `NOT_CONNECTED / WAITING_DELAYED_SAMPLE`。丢包时原因是 `SIMULATED_PACKET_LOSS`，已有样本为 `STALE`，尚无样本为 `INVALID`。在线且最近一包成功时，年龄恰好等于有效期仍为 `VALID`，超过有效期为 `STALE / SAMPLE_TOO_OLD`。成员失联时沿用链路原因。显示轨迹时按 `value.sequence` 识别新测量，按 `packet_sequence` 和 `lost_packets` 观察传输情况。

设备目录用布尔能力 `gnss_local_simulation` 声明已启用的局部误差模型。顶层 `gnss` 字段继续用于地理定位，其 `value=null`、`validity=NOT_CONNECTED`，对应设备能力 `gnss=false`。

## 已知边界与验证

当前漂移采用配置的线性偏移。两步之间的位置是线性估计，加速和急转时会有插值误差。GNSS 的采样周期、后端交付时刻和手机收帧间隔分别计量。真实卫星接收、卫星几何与遮挡、硬件定位精度及手机显示仍需各自验证。

11 月 18 日初版通过 164 项后端回归，其中 10 项覆盖模型、成员隔离及真实 HTTP/SSE 接口。动力学 26 项通过，另有 1 项历史实验产物检查按默认条件跳过。[后端回归摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json) · [动力学回归摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json)

开启 0.8 m 噪声、X 轴 0.02 m/s 漂移、80 ms 延迟和 10% 丢包，运行 30 秒三机混合负载。1,782 条运动收到回执，逐机 HTTP 往返 P95 为 6.39–6.57 ms，8 路 SSE 各实收 25 Hz。末帧各机的累积丢包数为 57、53、55，队列为 1–2 项，最后有效采样年龄为 88.9–104.9 ms。结果来自本机回环。[配置与测量摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json)

### 11 月 20 日对照实验

固定 20 Hz GNSS、5 秒直线运动、成员种子 101。每轮共采 101 个点，包含起始点。在 50 Hz 动力学下，初版相邻采样间隔为 40 或 60 ms，各 50 次。优化后 100 个间隔均为 50 ms。55 Hz 和 100 Hz 动力学复测也得到 100 个 50 ms 间隔。

固定 30% 丢包率，只将每轴噪声标准差从 0 调至 0.8 m。初版 101 次采样中有 47 次丢包结果随噪声改变，优化后为 0 次。固定 0.8 m 噪声，将丢包率从 0 调至 30% 后，优化版中两组共同收到的 67 个坐标逐个一致。恰好 50 ms 的边界样本也从误判过期恢复为有效，实测年龄达 50.2 ms 时按规则过期。[前后对照数据摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json)

开启 80 ms 延迟、0.8 m 噪声和 10% 丢包，三机在本机回环连续运行 30 秒。1,784 条运动指令获得回执，各机 HTTP 往返 P95 为 6.02–6.28 ms。8 路 SSE 各实收 24.97–25.00 Hz。末帧三架飞机的最后有效样本分别在采样后 80、90、80 ms 交付。2 号机最后一包丢失，保留第 600 号坐标，同时报告第 601 号包已处理及 `STALE / SIMULATED_PACKET_LOSS`。[三机测试摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json) · [逐机末帧摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json)

15 项 GNSS 专项全部通过，覆盖模型、成员隔离、独立三机和旧集群的 HTTP/SSE 读取。动力学 26 项通过，历史实验产物检查按原条件跳过 1 项。[GNSS 与后端复测摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json) · [动力学回归摘要](../docs/validation/后端GNSS与回放_20261121_验证摘要.json)
