# 第三轮自检 · 安全命令与回执容量

2026-11-13 · 独立三机模式

## 上一轮的复现

每架飞机的单个来源会话累积 1024 条离散记录后，原执行器会返回 `503 COMMAND_HISTORY_FULL`，导致新的 STOP 和 PROTECT 也被拒绝。试验中飞机继续处于 `ACTIVE`，查询原 STOP 的成功回执仍只能确认那条旧命令的结果。修复前的 HTTP 复现见本机 `results/doctor/command-history-limit.json`

## 本轮行为

| 项目 | 修复后的处理 |
| --- | --- |
| 普通离散命令 | 每架飞机的每个来源会话保留最多 1024 条。满额时，新普通命令返回 `503 COMMAND_HISTORY_FULL`，已有记录可查询或按原请求幂等重试。 |
| 安全动作 | STOP、PROTECT、DISCONNECT 独立保留最近 64 条成功回执，包含识别和映射后执行对应动作的指环与语音报文。普通历史达到上限时仍可提交。 |
| 回执滚动 | 第 65 条新安全动作执行成功后换出最早的一条。换出的 ID 查询返回 `404 COMMAND_NOT_FOUND`。失败、幂等重试和 ID 冲突均不消耗新的位置。 |
| 幂等与时效 | 回执仍在保留窗口时，同 ID、同动作、同请求内容返回原回执。跨动作或内容复用返回 `409 COMMAND_ID_REUSED`。已换出的旧报文仍受递增序号约束，重填时戳和轮次无法使旧序号生效。 |
| 权限与隔离 | 继续校验设备、来源、会话、TTL、序号和该动作原有的轮次要求。只读和跨机写入仍返回 403。安全动作只改变目标飞机的控制状态。 |
| 审计故障 | 三机保护策略继续生效。审计在请求入队后失效时，执行线程会再次检查，阻止普通请求推进，合法安全动作仍可执行并查询内存回执。 |

`--doctor` 的 `command_history` 中，`per_source_session_limit` 是普通记录上限，`safety_per_source_session_limit` 是安全回执上限，`recent_state_records` 是原始状态携带的最近摘要条数，当前分别为 1024、64 和 8。回执保存在当前会话内，换会话或重启后需用审计记录核对历史。审计写入故障期间的安全回执仍可从内存查到，实际落盘情况以审计健康和日志为准。自检输出见本机 `results/doctor/round3-capacities.json` · [三机前端对接](前端对接_三机独立操控.md)

## 复测方法

在 `backend` 目录用 `drone-sim-backend` 解释器运行。专项试验使用临时本机端口和隔离运行目录。

```powershell
python run_backend.py --mode independent --doctor
python -m unittest -v test_independent.IndependentTests.test_full_regular_history_accepts_fresh_stop_protect_and_disconnect test_independent.IndependentTests.test_safety_receipts_roll_without_dropping_regular_history_or_replaying_evicted_actions
python run_checks.py
python run_independent_acceptance.py --seconds 60 --out results/independent-round3-repeat
```

- 实际发送 1024 条普通离散命令后，下一条普通命令返回 `COMMAND_HISTORY_FULL`。随后连续运动进入 `ACTIVE`，新 STOP 返回 `HOLD`，新 PROTECT 返回 `PROTECTED`，断连回执为 `COMPLETED`。三个安全动作的回执均可按 ID 查询。另一架飞机继续运动，控制轮次保持稳定。
- 连续发出超过 128 条安全命令，确认回执数量保持在 64 条，普通回执仍可查。被换出的旧 STOP 无法凭旧序号再次执行。过期保护报文、冲突 ID、只读凭据和跨设备写入继续被拒绝。
- 在来源历史满额时验证指环 STOP、PROTECT、断连及语音悬停和保护。低置信度语音、重复指环事件和异常超大置信度值无法触发保护动作。另注入入队后的审计故障，验证映射后的安全动作仍可执行，普通会话替换被拒绝。
- 后端 148 项全部通过，包括 6 项新增安全回归。动力学 26 项通过，另有 1 项历史实验输出检查按默认条件跳过。[后端回归摘要](../docs/validation/后端三机_20261115_验证摘要.json) · [动力学回归摘要](../docs/validation/后端三机_20261115_验证摘要.json)
- 另做 60 秒本机三控四观验证。3570 条运动请求全部收到回执，三路 HTTP 往返 P95 为 4.77–5.06 ms，四路 SSE 各收到 1500 帧，为 25.00 Hz。审计队列正常排空。这些数值来自本机回环，手机刷新率和局域网时延待实测。60 秒验证记录见本机 `results/independent-round3-60s/summary.json`
