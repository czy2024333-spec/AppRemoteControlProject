# v0.7.2 全屏UE与透明HUD

本次继续更新手机已有“旋翼遥控·优化版”，包名和签名不变，版本码702；可覆盖此前v0.7/v0.7.1，不新增应用图标。

## 使用

1. 安装 `旋翼遥控APP-v0.7.2-覆盖更新.apk`，选择更新，不要先卸载已有版本。
2. 首页进入单机操纵。UE视频容器现在铺满整页；进入该页隐藏系统状态栏/导航栏，边缘滑动可临时调出，离开页面恢复。
3. 右上角齿轮打开“操控设置”，选择“连接”填写电脑IPv4和Token；控制流程仍是先观察，再主动申请。
4. 齿轮默认打开“显示”页，可分别调整摇杆、姿态仪、地图和位置数据的不透明度。
5. 设置即时生效并自动保存；点“恢复显示默认值”只恢复显示，不改变权限、控制参数或保护规则。

不透明度100%表示显示最清晰，20%表示更透明；保留最低20%避免控件完全不可见。
默认：摇杆65%、姿态仪85%、地图75%、位置数据85%。
“位置数据”指XYZ、接收频率和速度条；地图为独立滑块。

## 布局

- UE画面作为底层铺满窗口，控件不再挤占或缩小视频容器。
- 姿态仪和地图始终同时显示，无需切换；横屏分别位于靠左/靠右的上方内侧，竖屏位于上方两角。
- 双摇杆固定在下方两侧，低高度时自动缩放并预留标签空间。
- 顶部保留申请/解除、停止、保护、设置、旋转及返回；关键按钮不受显示透明度影响。
- 底部中间只有一条固定48dp提示，保护/失联时提高对比度，内容完整查看用“详情”。提示也不受HUD透明度影响。
- 进入设置或详情会停用运动输入；此前按住的手势必须实际松手后才能成为新的操纵。

透明度只改变显示。范围校验、控制权、真实松手判断、输入TTL与后端保护全部沿用原规则。
姿态仪仍仅由四元数驱动，XYZ位置变化不会直接驱动或重置姿态。

## 手机复测

1. 覆盖安装后，用原图标打开；后端地址和此前数据保留。
2. 横竖屏都能同时看到地图、姿态和摇杆，UE区域覆盖整页。
3. 把四个不透明度分别调低，检查对应控件变淡；停止、保护和提示不变淡。
4. 退出APP再打开，检查设置保留；恢复默认后各值还原。
5. 触发保护和断网，确认提示仍明显；未满足安全区/松手条件不能解除。
6. 持杆时进入设置、旋转或恢复连接，不应让原按压自动续发运动。

源码仍在原VrxFusionRemote-v0.7目录，Android Studio可继续打开原工程。本机签名路径在local.properties，交付包不含私钥和该本机配置。
