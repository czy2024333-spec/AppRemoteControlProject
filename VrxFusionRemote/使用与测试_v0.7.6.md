# v0.7.6 手机/电脑摄像头画面测试

日期：2026-10-17。覆盖安装已有“旋翼遥控·优化版”，不用卸载。视频仅替代UE预留底层，用于验证全屏、透明度、地图、姿态及摇杆叠加；不会产生UE三维场景，不参与动力学，不从图像估算飞行状态。

## 先用手机测试（不需要电脑视频服务）

1. 安装 `旋翼遥控APP-v0.7.6-覆盖更新.apk`，进入单机操控。
2. 齿轮 → **画面测试** → 选择 **手机摄像头** → 向下滚动点 **启用测试画面**。
3. 首次出现系统相机授权时点允许；默认使用后置镜头。也可打开“使用前置摄像头”。
4. 点设置顶部“完成”，检查摄像头铺满背景，地图、姿态仪、双摇杆和关键提示仍在上面。
5. 调整显示不透明度，检查画面与HUD叠加。摄像头可以在后端未连接时单独预览；飞行模型仍需连接原后端并主动申请控制。
6. 齿轮 → 画面测试 → 关闭测试画面，即恢复UE占位。离开操控页或将APP切到后台也会关闭，回来后要手动重新开启。

只选择源不会启动摄像头。仅请求相机权限，不请求麦克风，不录音、不录像；Android的相机隐私指示属于正常系统提示。
拒绝权限时会显示原因；如果系统不再弹授权提示，在手机系统设置 → 应用 → 旋翼遥控·优化版 → 权限中允许相机，再重新启用。
前置镜头的预览可能是镜像，仍以右上地图及坐标判断飞行方向，不能用手机画面的左右代替飞行坐标。

## 再用电脑摄像头（同一局域网）

1. 解压完整包，打开根目录 **电脑摄像头工具**，双击 **启动电脑摄像头.bat**。
2. 首次会联网下载OpenCV等依赖到这个组件自己的 `.deps` 目录，不改无人机动力学环境。后续直接启动即可。保持该窗口打开。
3. Windows若询问摄像头或局域网访问，允许本次测试使用。关闭正在占用镜头的会议、微信视频或系统相机。
4. 窗口启动成功会显示端口8768及本次随机生成的 **摄像头访问码**。用 `ipconfig` 查看电脑当前局域网IPv4。
5. APP → 齿轮 → 画面测试 → **电脑摄像头**。填写：

   - 电脑画面地址：`http://电脑IPv4:8768/video.mjpeg`
   - 摄像头访问码：复制电脑摄像头窗口给出的值，不要加Bearer。

6. 点“启用测试画面”，再点“完成”。这次使用电脑镜头，HUD仍由APP叠加。
7. 测试结束先在APP点“关闭测试画面”，再在电脑视频窗口按 `Ctrl+C` 释放摄像头。

访问码不是飞控Token：原后端仍是8765和 `demo-app-token-2026`；电脑画面使用8768和单独生成的访问码。访问码重启服务后会变化，只保留在APP当前进程内。
手机地址不能填0.0.0.0或127.0.0.1，也不要在URL里带访问码。视频采用本期组件的带Content-Length的MJPEG格式，不支持任意RTSP或网页链接。

若有多个电脑镜头，可在工具目录用PowerShell指定编号，例如：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_camera.ps1 -Camera 1 -InstallDependencies
```

默认电脑画面640×480、15fps，用于局域网联调。放大铺满时会保持比例并裁剪边缘；视频帧率不等于关键状态刷新频率，也不代表P95控制延迟。

## 没有电脑摄像头时验证传输

在工具目录运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_camera.ps1 -TestPattern -InstallDependencies
```

会发送带 `TEST PATTERN - NOT CAMERA` 水印的移动测试图，连接方法相同。这只能证明视频链路，不算真实摄像头或UE硬件验收。

## 复测项目

- 手机允许/拒绝相机权限都不崩溃，前后镜头切换正常；横竖屏不拉伸、不遮住HUD。
- 电脑镜头画面正常，访问码错误时给出提示，停止服务后显示断流，不冒充仍有实时画面。
- 画面播放时左右杆、停止及保护可操作；视频不改变控制权或飞机状态来源。
- 进入设置先停止摇杆输入，关闭设置需重新拨杆；摄像头和视频访问码不会触发自动接管。
- 退出操控页/切后台后关闭摄像头和网络流，回来后不会自动恢复画面或运动。

手机原生预览依据[Android官方CameraX预览接口](https://developer.android.com/media/camera/camerax/preview)；本期使用TextureView兼容模式供HUD混合显示。电脑组件使用[OpenCV官方Python组件](https://github.com/opencv/opencv-python)。具体测试范围见同包验证报告。
