# v0.9.1 连接与设备管理

本轮只升级前端入口与设备管理页，配套已有 v0.9 独立操控后端。原有全屏操纵、三机位置、状态总览、停止保护和控制适配层继续沿用；后端及 UE 实现未修改。

## 安装

安装 `旋翼遥控APP-v0.9.1-覆盖更新.apk`，覆盖现有“旋翼遥控·优化版”。包名及签名保持一致，版本 901 / 0.9.1，无需卸载或另装一个应用。

首页原“旧协议联调（高级）”已改为“连接与设备管理”。该入口不再打开旧 WebSocket 登录、角色选择或本地演示设备列表。旧页面源文件暂保留，但已退出 APP 导航；v0.9 控制所需的兼容适配代码仍保留。

## 后端启动

从仓库根目录打开 PowerShell，并使用已安装后端依赖的 Python 环境。

```powershell
Set-Location -LiteralPath .\backend
python .\run_backend.py --mode independent --host 0.0.0.0 --port 8765
```

手机与电脑连接同一局域网，APP 填 `http://电脑IPv4:8765`。

## 连接与身份

1. 首页点“连接与设备管理”，填写地址，选择操纵端1、2、3或观察端预设。身份预设可左右滑动。
2. 点“连接并查看状态”。连接本身只准备状态读取，不自动申请控制、不发送运动输入。
3. 向下查看“后端确认身份”。操纵端2应看到客户端 `pilot-2`、本端绑定 `sim-drone-2`；其他操纵端依此对应。观察端没有绑定操纵飞机。
4. 预设只是填写凭据，下方身份和设备权限以后端确认为准。自定义 Token 只保留在当前进程，Token 不是正式用户登录或管理员账号。
5. 目录显示后端实际返回的成员、仿真/实机类型、状态、位置、速度、当前通路和测量有效性。本端飞机突出显示，其他成员仅供观察。管理页没有接管、运动或切换控制目标的按钮。

横屏时，左侧连接设置与右侧身份/设备区域独立滚动，顶部返回和连接状态保留。

## 进入操纵与更换身份

- 管理页连接后点“返回”，再进入“独立操纵”，可以复用当前前台连接。保持双摇杆松手，主动点“申请控制”后才建立会话。
- 观察端仍只能观察，进入操纵页不会获得操纵权限。
- 离开操纵页继续执行原有停流和释放逻辑。更换身份或地址要先断开，再选择凭据、连接并确认实际绑定；旧运动不会自动恢复。
- APP 进入后台会停止观察和释放控制，回到前台后需主动重新连接；返回首页本身不会让管理页的观察连接自动断开。

## 先按这些项目复测

| 用例 | 操作 | 应有结果 |
|---|---|---|
| 新入口 | 点“连接与设备管理” | 不出现旧 WebSocket 登录、手选角色和本地演示设备 |
| 操纵端身份 | 选操纵端2并连接 | 后端确认 pilot-2 / sim-drone-2；只有本端飞机显示可到操纵页申请 |
| 观察端 | 选观察端连接 | 可看三机，不能接管或操纵 |
| 页面复用 | 管理页连接，返回首页，进入独立操纵 | 无需再次填写或连接；仍先观察，点申请才接管 |
| 错误 Token | 断开后填无效 Token 并连接 | 显示失败，不回退旧协议，不生成演示设备 |
| 目录失败 | 能力目录获取失败 | 显示目录待确认；不从缓存或本地数据补出可操作目录 |
| 单机过期 | 一个成员停止更新 | 该成员标过期、坐标与速度失效；不借其他成员更新伪装实时 |
| 断网/断开 | 断开网络或主动断开 | 保留历史标识；历史身份不代表当前认证，坐标不显示为实时 |
| 后台恢复 | APP 进入后台，再回前台 | 连接停止，需手动重连，旧控制和运动不恢复 |
| 横竖屏 | 旋转手机并滚动设备 | 无另一个操纵窗口，返回和状态清楚可见 |

本轮没有补齐正式账号体系、旧版全部任务按钮或实际外设接入。未接入能力仍按后端能力和状态显示。自动化测试与手机现场结果分开记录，详细结果见本版验证报告。
