# 旋翼遥控 APP v0.9.3 · 界面过渡动画

在原优化版中覆盖迭代，配套现有 v0.9 后端的 `--mode independent`。包名 `com.vrxfusion.remote.optimized`，版本 903 / 0.9.3。

## 本轮变化

独立操纵固定为横屏，支持左右翻转，退出后恢复进入前的方向策略。顶部操作集中排列，位置与速度采用紧凑衬底，视频背景采用轻微深色渐变。版本仍为903 / 0.9.3。

增加iPhone风格的层级推进/返回、弹性设置面板、分类切换和卡片按压反馈。切页先停流释放；设置收起结束前保持摇杆拦截，固定安全区保持可用。系统关闭动画时直接切换。

0.9.3 小修整合了底部提示、系统栏安全区、实时布局预览、设置收起和界面视觉。根据横屏实拍将断线提示缩为左上提示卡，视频接入状态移到右上。窄横屏会缩小并固定显示预览，调节时同步显示结果。

修正源码打包过滤，完整包含日志代码；所有app/src文件逐个验证。

首页保留独立操纵和三机总览两个工作入口，“连接与设备管理”作为次级入口，使用同一生产连接确认实际身份、绑定和设备能力。从工作页进入管理时先退出当前操纵，连接确认后可返回原工作页，仍须主动申请控制。管理页不再重复显示位置、速度和告警详情。

地址与Token只在管理页编辑，工作页提供摘要和跳转。日志按后端能力开放，支持固定快照查询和有界文件导出，详见本版使用说明。显示默认恢复沿用原按钮并保存回退点。

本轮未修改后端、UE或原有运动控制适配器。旧WebSocket页面和历史服务源码暂留归档，已退出APP导航；当前联调无需运行历史 `server/` 服务。

## 安装与测试

安装交付目录中的 `旋翼遥控APP-v0.9.3-覆盖更新.apk`，覆盖现有“旋翼遥控·优化版”，无需卸载。

1. 启动v0.9后端，使用 `--mode independent --host 0.0.0.0 --port 8765`。
2. 手机与电脑在同一局域网，在“连接与设备管理”填 `http://电脑IPv4:8765`。
3. 选择操纵端或观察端预设并连接，先确认下方后端实际身份与绑定设备。
4. 首轮先复测连接、身份与历史提示，再返回首页进入独立操纵，主动申请控制。

完整启动命令与逐项检查见 [本版使用与复测](界面动效_使用与复测_v0.9.3.md)，自动化结果和现场限制见 [本版验证报告](验证报告_v0.9.3.md)。三机操纵操作继续参照 [v0.9.0三机联调说明](使用与三机联调_v0.9.0.md)。

## 打开与编译源码

Android Studio打开本目录（含 `settings.gradle.kts`），Gradle JDK选择17，使用项目Gradle Wrapper。minSdk29（Android10），targetSdk34。安装Android SDK34和Build Tools34.0.0，等待依赖同步，再运行 `app`。

命令行编译为 `./gradlew.bat assembleDebug`，测试为 `./gradlew.bat testDebugUnitTest`。本机本次构建使用Gradle8.7、AGP8.5.2与JDK17。自行构建使用你电脑的签名；若要覆盖已有安装，应使用原开发签名，交付包不包含私钥。
